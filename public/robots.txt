# https://hatoove.com — crawler policy
#
# Only the API is disallowed. The private pages (/app/, /reset-password, /verify-email) are kept
# crawlable ON PURPOSE: they answer with `X-Robots-Tag: noindex` (and /app/ is behind the session
# gate), and a page that robots.txt disallows can never be fetched, so its noindex would never be
# read. Disallowing them would leave them eligible for URL-only indexing from links.
User-agent: *
Allow: /
Disallow: /api/

Sitemap: https://hatoove.com/sitemap.xml
